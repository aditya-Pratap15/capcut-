💡 How OmniCut Instruction Editing Works

OmniCut is an instruction-driven video editing engine. Instead of manually slicing audio and dragging subtitles on a timeline, you provide an instruction JSON file that defines commentary scripts, timestamps, ducking levels, and styles. OmniCut parses and executes everything automatically.

📑 JSON Schema & Properties Explained

Property Key Type Description Example
metadata.project_name String Project name used when exporting files. "My_Story_Edit"
metadata.target_ratio String Aspect ratio: "9:16" (Shorts/Reels), "16:9" (Landscape), "1:1" (Square). "9:16"
metadata.fps Number Target frame rate (typically 30 or 60). 30
voiceover[].timestamp_sec Float Exact second in the video when speech begins. 0.5
voiceover[].voice String Kokoro voice ID: "am_eric" (Warm Broadcaster), "am_adam", "af_bella", "af_nicole". "am_eric"
voiceover[].speed Float Speech speed multiplier (1.0 = standard, 1.05 = engaging Shorts pace). 1.05
voiceover[].volume Float Voice volume multiplier (1.0 = normal, 1.2 = clear loud commentary). 1.2
voiceover[].text String The commentary script or narration sentence to speak. "When this stranger stepped in..."
audio_ducking[].start_sec Float Timestamp when background video audio drops. 0.0
audio_ducking[].end_sec Float Timestamp when background video audio returns to full. 6.5
audio_ducking[].original_volume Float Target background volume: 0.2 (20% background), 1.0 (100% full volume), 0.0 (mute). 0.25
captions.style Object Styles: font_family, font_size_px, text_color, highlight_color, animation, position_y_percent. {"font_size_px": 42}
captions.segments[] Array Subtitle cues with start_sec, end_sec, and text. {"start_sec": 0.5, "end_sec": 5.0, "text": "..."}
effects.watermark_removal[] Array Box coordinates: start_sec, end_sec, x_percent, y_percent, width_percent, height_percent, mode. {"x_percent": 70, "mode": "mosaic"}
effects.face_tracking Object Privacy face blur: enabled (boolean), mode ("gaussian"), blur_radius_px. {"enabled": false}

    "target_ratio": "9:16",
    "fps": 30
  },
  "voiceover": [
    {
      "timestamp_sec": 0.5,
      "voice": "am_eric",
      "speed": 1.05,
      "volume": 1.2,
      "text": "Enter your opening commentary or story hook here."
    },
    {
      "timestamp_sec": 8.0,
      "voice": "am_eric",
      "speed": 1.05,
      "volume": 1.2,
      "text": "Enter your key narrative, punchline, or concluding takeaway here."
    }
  ],
  "audio_ducking": [
    {
      "start_sec": 0.0,
      "end_sec": 6.0,
      "original_volume": 0.25,

    },
    {
      "start_sec": 6.0,
      "end_sec": 8.0,
      "original_volume": 1.0,
      "description": "Restore 100% full original video audio during natural action"

    {
      "start_sec": 8.0,

      "description": "Duck background video volume during closing voiceover"
    }
  ],
  "captions": {

      "font_family": "Impact, Inter, sans-serif",
      "font_size_px": 42,

      "animation": "pop_bounce",
      "position_y_percent": 78
    },
    "segments": [
      {
        "start_sec": 0.5,
        "end_sec": 6.0,
        "text": "Enter your opening commentary or story hook here."
      },
      {
        "start_sec": 8.0,
        "end_sec": 14.0,
        "text": "Enter your key narrative, punchline, or concluding takeaway here."
      }
    ]
  },
  "effects": {
    "watermark_removal": [
      {
        "start_sec": 0.0,
        "end_sec": 20.0,
        "x_percent": 70,
        "y_percent": 5,

      }
    ],

    }
  }
